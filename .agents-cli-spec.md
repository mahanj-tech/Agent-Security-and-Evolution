# Agent Spec

## Overview
The **Ambient Expense Agent** is an autonomous personal finance assistant designed to track and categorize daily expenses in the background ("ambiently"). It monitors transaction sources (such as receipts and transactions from Gmail/emails or receipt images via OCR) and organizes them into a structured Google Sheets spreadsheet without requiring manual user intervention.

## Example Use Cases
* **Email receipt processing**: The agent scans incoming emails from Gmail, identifies receipt/transaction emails (e.g., Uber rides, restaurant bills, Amazon invoices), extracts relevant details (vendor, date, amount, category), and appends them to a designated Google Sheets spreadsheet.
* **Receipt Image processing (OCR)**: The agent processes receipt images uploaded/received, runs OCR via Vision API to extract vendor, line items, total amount, and appends the structured data to the Google Sheets spreadsheet.

## Tools Required
* **Gmail Reader Tool**: Read-only tool to search and fetch recent emails matching transaction patterns.
* **Vision OCR Tool**: Run OCR analysis on receipt images (via Google Vision API).
* **Google Sheets Tool**: Append rows, edit worksheets, and retrieve current structures of the expense spreadsheet.

## Constraints & Safety Rules
* **Gmail Read-Only Constraint**: The agent must have strict read-only access to Gmail. It must **never** delete, archive, modify, or send any emails.
* **No Financial Actions**: The agent must **never** perform financial transactions, make purchases, or access payment interfaces.
* **No External Data Sharing**: Personal financial data, transaction histories, and email contents must never be shared with any external third parties or servers outside the authorized project environment.
* **Strict Sheets Writing**: The agent must only write to the designated expense spreadsheet and authorized worksheets.

## Success Criteria
* Correctly categorizes and records 90%+ of transaction emails.
* Extract accurate transaction amounts, dates, and vendor names from receipt emails and images.
* Adhere strictly to the safety guidelines (read-only Gmail, no purchases, no external leaks).
